# Triage Matrix

- `security`: user harm, auth bypass, data exposure, dependency CVE, incident follow-up.
- `bug`: broken behavior, crash, incorrect output, regression from previous release.
- `feature`: new capability, workflow expansion, integration, UX improvement, automation.
- `docs`: missing or stale docs, onboarding friction, examples, runbooks.
- `release`: version planning, release blocking, deployment sequencing, rollback readiness.

Escalate severity when the item mentions production, outage, customer impact, or compliance exposure.
