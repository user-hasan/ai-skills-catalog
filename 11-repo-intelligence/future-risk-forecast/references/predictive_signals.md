# Predictive Signals

- High centrality plus low test coverage is a near-term failure signal.
- High churn plus high centrality is a medium-term fragility signal.
- Dense TODO or FIXME markers inside key files are a warning that local complexity is still accumulating.
- Ownerless or weakly owned critical paths should be flagged separately from code quality issues.
- Future risks must include both `time_horizon` and `trigger_signals`.
